📖 简介

OpenClaw 是一个强大的 AI 自动化代理平台。它支持多渠道消息接入（如 Discord、Telegram、WhatsApp 等），并提供丰富的工具扩展能力。

通过 OpenClaw，您可以快速构建 AI 驱动的聊天机器人、自动化工作流和智能助手。

⚙️ 系统要求

组件 要求 说明
Node.js Node 24 推荐 (Node 22.14+ 支持) 必需
API Key Anthropic / OpenAI / Google 等 至少一个模型提供商
Windows 原生 Windows 或 WSL2 WSL2 更稳定，推荐使用
💡 检查 Node 版本

运行 node --version 检查您的 Node.js 版本。

🖥️ 选择您的平台

快速安装

终端
# 一键安装脚本 curl -fsSL https://openclaw.ai/install.sh | bash

运行新手引导

终端
# 运行引导并安装守护进程 openclaw onboard --install-daemon

验证安装

终端
# 检查 Gateway 状态 openclaw gateway status # 打开控制面板 openclaw dashboard
💡 快速开始

引导程序会帮助您选择模型提供商、设置 API 密钥并配置 Gateway，整个过程约 2 分钟。

💡 Windows 支持

OpenClaw 同时支持原生 Windows 和 WSL2。WSL2 更稳定，推荐用于完整体验。

原生 Windows 安装

PowerShell
# 使用 PowerShell 安装脚本 iwr -useb https://openclaw.ai/install.ps1 | iex

WSL2 安装（推荐）

PowerShell (管理员)
# 安装 WSL wsl --install # 重启后打开 WSL 终端
WSL 终端
# 安装 Node.js curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - sudo apt-get install -y nodejs # 安装 OpenClaw curl -fsSL https://openclaw.ai/install.sh | bash # 运行引导 openclaw onboard --install-daemon

验证安装

终端
openclaw gateway status openclaw dashboard

🔧 配置 Bridgemind API

在引导过程中，您可以选择自定义 API 端点以使用 Bridgemind 服务：

配置示例
{ "providers": { "openai": { "apiKey": "your-bridgemind-api-key", "baseUrl": "https://bridgemind.pro/v1" } } }
💡 支持的渠道

OpenClaw 支持 Discord、Feishu、iMessage、Matrix、Microsoft Teams、Signal、Slack、Telegram、WhatsApp、Zalo 等多种消息渠道。

🚀 基本使用

常用命令

  • openclaw onboard - 运行配置向导
  • openclaw gateway status - 检查 Gateway 状态
  • openclaw gateway start - 启动 Gateway
  • openclaw gateway stop - 停止 Gateway
  • openclaw dashboard - 打开控制面板
  • openclaw --help - 查看帮助

首次使用流程

  1. 运行 openclaw onboard --install-daemon
  2. 选择模型提供商（Anthropic/OpenAI/Google 等）
  3. 输入 API 密钥
  4. 验证 Gateway 正在运行
  5. 打开 Dashboard 发送第一条消息
