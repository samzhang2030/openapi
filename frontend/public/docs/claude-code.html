📖 简介

Claude Code 是由 Anthropic 公司开发的一款具有代理（Agentic）能力的命令行界面（CLI）工具，它直接在开发者的终端环境中运行。其核心设计理念是与开发者偏好的集成开发环境（IDE）和工具链无缝协作，而非取而代之。

该工具能够理解整个代码库的上下文，通过自然语言指令执行日常开发任务、解释复杂代码逻辑，乃至处理 Git 工作流。

🖥️ 选择您的平台

安装 Node.js (如已安装可跳过)

推荐使用 Homebrew 安装 Node.js：

终端
# 如果没有安装 Homebrew，请先运行 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # 安装 Node.js brew install node # 验证安装 node --version

安装 Claude Code

终端
npm install -g @anthropic-ai/claude-code # 验证安装 claude --version
⚠️ 重要提示

请勿使用 sudo 执行安装命令，这可能导致权限问题和安全风险。如遇权限错误，请修复 npm 权限配置。

配置 API 密钥

首次运行时，Claude Code 会提示您输入 API 密钥。您可以使用 Bridgemind 提供的统一接入服务：

终端 - 配置环境变量
# 设置 API Base URL (使用 Bridgemind 服务) export ANTHROPIC_BASE_URL="https://bridgemind.pro/v1" # 设置 API 密钥 export ANTHROPIC_AUTH_TOKEN="your-api-key-here" # 运行 Claude Code claude
💡 提示

您可以将环境变量添加到 ~/.zshrc 或 ~/.bash_profile 以永久保存配置。

💡 Windows 用户提示

Claude Code 现在支持在原生 Windows 的 CMD 和 PowerShell 中直接运行；如果您更习惯类 Unix 环境，也可以继续使用 Git Bash 或 WSL。

安装 Node.js

请先从 Node.js 官网 安装最新版 LTS（建议 18+，推荐 20+），安装完成后重新打开 CMD 或 PowerShell。

CMD / PowerShell
# 验证 Node.js 和 npm node --version npm --version

安装 Claude Code

CMD / PowerShell
npm install -g @anthropic-ai/claude-code # 验证安装 claude --version
⚠️ 安装提示

如果全局安装时遇到权限或执行策略问题，请优先使用管理员 PowerShell，或按 Node.js/npm 官方建议修复环境配置；通常不需要依赖 WSL。

配置 API 密钥

PowerShell - 配置环境变量
# 设置 API Base URL (使用 Bridgemind 服务) $env:ANTHROPIC_BASE_URL="https://bridgemind.pro/v1" # 设置 API 密钥 $env:ANTHROPIC_AUTH_TOKEN="***" # 运行 Claude Code claude
CMD - 配置环境变量
set ANTHROPIC_BASE_URL=https://bridgemind.pro/v1 set ANTHROPIC_AUTH_TOKEN=*** claude
🔁 可选方案

如果您团队内部仍使用 Git Bash 或 WSL，也可以继续在这些终端中运行 Claude Code，但它们不再是 Windows 的前置要求。

安装 Node.js

Ubuntu / Debian
# 使用 NodeSource 安装 Node.js 20.x curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - sudo apt-get install -y nodejs # 验证安装 node --version
Arch Linux
# 使用 pacman 安装 sudo pacman -S nodejs npm # 验证安装 node --version

安装 Claude Code

终端
npm install -g @anthropic-ai/claude-code # 验证安装 claude --version
⚠️ 重要提示

请勿使用 sudo 执行安装命令。如遇权限错误（如 EACCES），请修复 npm 权限配置。

配置 API 密钥

终端 - 配置环境变量
# 设置 API Base URL (使用 Bridgemind 服务) export ANTHROPIC_BASE_URL="https://bridgemind.pro/v1" # 设置 API 密钥 export ANTHROPIC_AUTH_TOKEN="your-api-key-here" # 运行 Claude Code claude
💡 提示

您可以将环境变量添加到 ~/.bashrc 或 ~/.zshrc 以永久保存配置：

添加到 ~/.bashrc
echo 'export ANTHROPIC_BASE_URL="https://bridgemind.pro/v1"' >> ~/.bashrc echo 'export ANTHROPIC_AUTH_TOKEN="your-api-key-here"' >> ~/.bashrc source ~/.bashrc

🚀 基本使用

安装完成后，进入您的项目目录并运行 Claude Code：

终端
cd /path/to/your/project claude

常用命令

  • claude - 启动交互式会话
  • claude "your prompt" - 直接发送提示并获取响应
  • claude --help - 查看帮助信息
  • claude --version - 查看版本信息

交互式会话中的常用操作

  • 直接输入自然语言描述您想要完成的任务
  • Claude Code 可以读取、修改和创建文件
  • 支持执行终端命令（会请求您的确认）
  • 可以分析整个代码库的结构和逻辑
