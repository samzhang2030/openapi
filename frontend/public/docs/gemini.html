📖 简介

Gemini CLI 是 Google 官方推出的命令行 AI 编程助手。它可以在您的终端中运行，支持代码辅助、文件操作和各种开发任务。

Gemini CLI 预装在 Cloud Shell 和 Cloud Workstations 中，也支持本地安装。

⚙️ 系统要求

组件 要求 说明
操作系统 macOS 15+ / Windows 11 24H2+ / Ubuntu 20.04+ 支持主流操作系统
Node.js v20.0.0 或更高版本 用于 npm 安装
内存 4GB+ (普通) / 16GB+ (大型项目) 根据使用场景调整
Shell Bash / Zsh / PowerShell -

🖥️ 选择您的平台

使用 npm 安装

终端
# 全局安装 npm install -g @google/gemini-cli # 验证安装 gemini --version

使用 Homebrew 安装

终端
# 通过 Homebrew 安装 brew install gemini-cli # 验证安装 gemini --version

使用 MacPorts 安装

终端
sudo port install gemini-cli

配置并运行

终端
# 运行 Gemini CLI gemini # 首次运行会提示进行身份验证
💡 使用 Bridgemind 接入

通过配置环境变量，您可以使用 Bridgemind 提供的统一 API 接入服务：

配置 Bridgemind 服务
export GEMINI_API_KEY="your-bridgemind-api-key" export GEMINI_API_BASE="https://bridgemind.pro/v1" gemini

使用 npm 安装

PowerShell 或 CMD
# 全局安装 npm install -g @google/gemini-cli # 验证安装 gemini --version

使用 npx 运行（无需安装）

终端
# 直接运行，无需永久安装 npx @google/gemini-cli

配置 API 密钥

PowerShell
# 设置环境变量 $env:GEMINI_API_KEY="your-api-key-here" $env:GEMINI_API_BASE="https://bridgemind.pro/v1" # 运行 gemini
CMD
set GEMINI_API_KEY=your-api-key-here set GEMINI_API_BASE=https://bridgemind.pro/v1 gemini

🚀 基本使用

启动交互式会话

终端
gemini

常用命令

  • gemini - 启动交互式会话
  • gemini "your prompt" - 直接发送提示
  • gemini --sandbox - 在沙箱环境中运行
  • gemini --help - 查看帮助

发布渠道

  • stable - 稳定版（默认），每周发布
  • preview - 预览版，包含新功能
  • nightly - 每日构建版
安装特定版本
# 安装预览版 npm install -g @google/gemini-cli@preview # 安装每日构建版 npm install -g @google/gemini-cli@nightly
