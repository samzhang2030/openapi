📖 简介

Codex CLI 是 OpenAI 的编程代理，您可以在本地终端运行它。它可以读取、更改和在选定目录中运行代码。它是开源的，用 Rust 构建以提高速度和效率。

ChatGPT Plus、Pro、Business、Edu 和 Enterprise 计划都包含 Codex 访问权限。您可以使用 ChatGPT 账户或 API 密钥进行身份验证。

⚙️ 系统要求

组件 要求 说明
操作系统 macOS / Linux / Windows (WSL2) Windows 支持处于实验阶段
Node.js v18.0 或更高版本 用于 npm 安装
账户 ChatGPT Plus/Pro/Enterprise 或 API Key 需要有效的访问权限

🖥️ 选择您的平台

使用 npm 安装

终端
# 全局安装 Codex CLI npm install -g @openai/codex # 验证安装 codex --version

使用 Homebrew 安装

终端
brew install openai-codex # 验证安装 codex --version

配置 API 密钥

首次运行时，Codex 会提示您登录。您可以使用 ChatGPT 账户或 API 密钥进行身份验证。使用 Bridgemind 服务时：

终端 - 配置环境变量
# 设置 API Base URL (使用 Bridgemind 服务) export OPENAI_BASE_URL="https://bridgemind.pro/v1" # 设置 API 密钥 export OPENAI_API_KEY="your-api-key-here" # 运行 Codex codex
💡 使用 Bridgemind 的优势

通过 Bridgemind 接入，您可以访问 GPT-5.4、GPT-5.3 等最新模型，并享受统一计费和多模型切换能力。

⚠️ Windows 用户注意

Windows 支持目前处于实验阶段。建议在 WSL2 工作区中使用 Codex 以获得最佳体验。

安装 WSL2

PowerShell (管理员)
# 安装 WSL wsl --install # 重启后，打开 WSL 终端继续

在 WSL 中安装 Node.js

WSL 终端
# 安装 Node.js curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - sudo apt-get install -y nodejs # 验证 node --version

安装 Codex CLI

WSL 终端
# 全局安装 npm install -g @openai/codex # 运行 codex

配置 API 密钥

WSL 终端
export OPENAI_BASE_URL="https://bridgemind.pro/v1" export OPENAI_API_KEY="your-api-key-here" codex

# 安装 Node.js (如未安装) curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - sudo apt-get install -y nodejs # 安装 Codex CLI npm install -g @openai/codex # 验证安装 codex --version

💡 永久保存配置

将环境变量添加到 ~/.bashrc 或 ~/.zshrc 以永久保存配置。

🚀 基本使用

启动交互式会话

终端
cd /path/to/project codex

常用命令

  • codex - 启动交互式终端 UI (TUI) 会话
  • codex "your prompt" - 直接发送提示
  • /model - 切换模型（GPT-5.4、GPT-5.3-Codex 等）
  • /help - 查看帮助信息

主要功能

  • 代码审查 - 在提交或推送前获取代码审查
  • 图像输入 - 附加截图或设计规范
  • Web 搜索 - 获取最新的网络信息
  • 子代理 - 并行处理复杂任务
  • MCP 支持 - 通过 Model Context Protocol 接入第三方工具

批准模式

Codex 提供多种批准模式，让您控制它在编辑文件或运行命令前的行为：

  • suggest - 仅建议更改（默认）
  • auto-edit - 自动编辑文件
  • full-auto - 完全自动模式
