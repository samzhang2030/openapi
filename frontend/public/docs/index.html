📌 实际接入只需要 3 步

先看对应客户端教程，再登录 Bridgemind 创建 API Key，最后用 Key 用量页确认请求是否正常到达。文档是公开的，真正配置时再登录即可。

  • 登录 / 注册后，在 Bridgemind 控制台创建 API Key
  • 把客户端中的 API Base URL 改成 Bridgemind 提供的地址
  • 接入完成后，用 Key 用量页或控制台核对请求和额度状态
