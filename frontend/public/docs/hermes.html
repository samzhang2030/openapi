📖 简介

Hermes Agent 是由 Nous Research 开发的开源 AI 代理。它是一个业内少见的原生内置学习闭环的 AI Agent，可从执行经验中沉淀技能、自主优化能力、持久化知识、检索历史对话，并在跨会话中持续完善用户认知模型。

Hermes 支持多种 LLM 提供商，并提供了丰富的工具集成能力。

⚙️ 系统要求

组件 要求 说明
Python Python 3.10+ 推荐使用 conda 或 venv
API Key 支持多种 LLM 提供商 OpenAI / Anthropic / Google 等
内存 建议 8GB+ 取决于使用场景

🖥️ 选择您的平台

使用 pip 安装

终端
# 创建虚拟环境（推荐） python -m venv hermes-env source hermes-env/bin/activate # 安装 Hermes Agent pip install hermes-agent # 或者从 GitHub 安装最新版 pip install git+https://github.com/NousResearch/hermes-agent.git

运行 Hermes

终端
# 启动交互式对话 hermes model # 配置工具 hermes tools # 查看帮助 hermes --help

配置 LLM 提供商

终端
# 使用环境变量配置 export OPENAI_API_KEY="your-api-key" export OPENAI_BASE_URL="https://bridgemind.pro/v1" # 或配置 Anthropic export ANTHROPIC_API_KEY="your-api-key" export ANTHROPIC_BASE_URL="https://bridgemind.pro/v1" # 运行 hermes model

💡 使用 Bridgemind

通过 Bridgemind API，您可以访问多种模型，包括 GPT、Claude 和 Gemini 系列。

🚀 基本使用

主要命令

  • hermes model - 启动交互式 CLI，选择模型开始对话
  • hermes tools - 配置可用的工具
  • hermes --help - 查看帮助信息

核心特性

  • 学习闭环 - 从执行经验中沉淀技能和知识
  • 多提供商支持 - 支持多种 LLM 提供商
  • 工具集成 - 丰富的工具扩展能力
  • 历史检索 - 检索历史对话，跨会话持续优化

与 OpenClaw 配合使用

Hermes Agent 可以与 OpenClaw 配合使用，构建更强大的 AI 自动化解决方案。OpenClaw 提供 Gateway 和多渠道接入能力，Hermes 提供智能代理和学习能力。
