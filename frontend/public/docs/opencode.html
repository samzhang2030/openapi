📖 简介

OpenCode 是一个开源的 AI 编程代理。它提供终端界面、桌面应用和 IDE 扩展多种使用方式，让您可以灵活选择最适合的工作流程。

OpenCode 支持多种 LLM 提供商，您可以根据需要配置不同的 API 密钥。

终端模拟器 WezTerm / Alacritty / Ghostty / Kitty 等 推荐现代终端
API Keys LLM 提供商的 API 密钥 支持多种提供商

🔧 配置 API 提供商

OpenCode 支持多种 LLM 提供商。您可以使用 /connect 命令配置：

使用 OpenCode Zen（推荐新手）

  1. 运行 /connect 命令
  2. 选择 "opencode"
  3. 访问 opencode.ai/auth 获取 API 密钥
  4. 粘贴您的 API 密钥

使用 Bridgemind 服务

配置环境变量以使用 Bridgemind 作为 API 网关：

终端
# 设置 OpenAI 兼容的 API export OPENAI_API_KEY="your-bridgemind-api-key" export OPENAI_BASE_URL="https://bridgemind.pro/v1" # 运行 OpenCode opencode

🚀 基本使用

常用命令

  • /init - 初始化项目，创建 AGENTS.md 文件
  • /connect - 配置 LLM 提供商
  • /undo - 撤销最近的更改
  • /redo - 重做撤销的更改
  • /share - 分享当前对话

工作模式

  • Build 模式 - 默认模式，可以直接修改代码
  • Plan 模式 - 仅建议更改，不实际修改（按 Tab 切换）
